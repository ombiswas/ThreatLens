# Security Policy

## Supported Versions
Only the latest version of AI CyberShield is actively maintained with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within this project:
1. Please do **NOT** open a public issue.
2. Email the maintainer or project supervisor with a detailed description of the vulnerability, reproduction steps, and potential impact.
3. You will receive an acknowledgment within 48 hours.
4. Validated issues will be addressed with priority fixes and detailed in the project changelog.
